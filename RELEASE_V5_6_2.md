# Qulay v5.6.2 — Premium Navy + Gold Theme

## Visual system
- Dark: `#0d1117` app, `#161b22` surface, `#1e3a5f` primary, `#e0b84b` CTA, `#f0f0f0` text, `#a0a0a0` secondary, `#2a2f3a` border.
- Light: `#faf9f6` app, `#ffffff` surface, `#0a2a43` primary, `#c9a227` CTA, `#1c1c1c` text, `#5c5c5c` secondary, `#e5e2db` border.
- Primary navigation and active states remain navy/blue; high-priority CTA uses restrained gold.
- Shared theme layer now covers navigation, KPI/cards, tables, forms, overlays, operations, help, fulfillment, delivery/routes, finance/report surfaces, settings, Super Admin and POS.
- Light mode preserves the same visual language as dark mode instead of becoming a flat white theme.

## Fulfillment
- Products and activity history are now separated into premium cards.
- Activity history uses compact timeline rows with icon, title, description and formatted date/time.

## Compatibility
- Legacy Qulay default green is migrated to the new navy default at runtime/data-normalization level.
- A genuinely customized company brand color is preserved.
- Backend was not modified.
